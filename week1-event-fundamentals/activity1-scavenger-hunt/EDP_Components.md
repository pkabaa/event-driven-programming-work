| System | Event Source | Event | Listener | Handler / Action |
|---|---|---|---|---|
| **ATM Machine Operation** | Keypad button | Button pressed | ATM software | Verify PIN |
| **Microwave Oven Use** | Start button / Door latch | Button pressed / Door opened | Microwave microcontroller | Start magnetron timer / Cut power immediately |
| **Traffic Light System** | Internal timer / Road inductive loop sensor | Countdown expired / Vehicle detected | Traffic signal controller | Switch signal from green to yellow to red |
| **Video Game Gameplay** | Keyboard / Game controller | Spacebar or jump button pressed | Game input manager | Apply upward velocity and play jump animation |
| **Elevator Operation** | Floor call button / Weight sensor | Button pressed / Overload triggered | Elevator control board | Dispatch car to requested floor / Keep doors open and sound buzzer |
| **Smartphone Touchscreen** | Capacitive touch digitizer | Screen tapped or swiped | OS touch event dispatcher | Open selected app or scroll the view |
| **Supermarket Self-Checkout** | Barcode laser scanner | Barcode scanned | POS checkout software | Look up item price and add to receipt total |
| **Car Dashboard** | Fuel level float sensor / Seatbelt buckle | Fuel drops below threshold / Belt unbuckled | Vehicle ECU / Body control module | Illuminate low-fuel warning light / Trigger chime |
