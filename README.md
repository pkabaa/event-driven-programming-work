# Event-Driven Programming Work

This repository contains my Event-Driven Programming coursework, organised by week.

## Weekly work

1. **Week 1 – Event Fundamentals**
2. **Week 2 – Observer Pattern**
3. **Week 3 – Swing GUI**
4. **Week 4 – Event Handling**
5. **Week 5 – Advanced Swing**
6. **Week 6 – JavaFX**
7. **Week 7 – JavaFX Events**
8. **Week 8 – JavaFX Bindings**
9. **Week 9 – Async JavaFX**
10. **Week 10 – University System**

Each weekly folder contains the source code and any supporting resources or documentation provided for that week.

## Notes

- Java source files (`.java`), JavaFX layout files (`.fxml`), SQL files, Markdown notes, and project configuration files are retained.
- Compiled Java files (`.class`), generated Maven build output (`target/`), and compiler-generated `.lst` files are excluded because they can be regenerated.
